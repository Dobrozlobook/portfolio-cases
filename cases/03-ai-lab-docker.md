# Локальная ИИ-лаборатория: бот вместо колл-центра

## Задача

Проверить, можно ли заменить колл-центр ботом. Нужна была площадка, где быстро собираются цепочки из блоков: бот, текстовые и голосовые обращения, звонки. И чтобы всё поднималось одной командой на любом компьютере.

## Как устроено

1. `docker-compose.yml` описывает сервисы: n8n и Flowise. Каждый запускается в своём контейнере, порты проброшены на localhost.
2. В n8n и Flowise собраны цепочки: приём обращений, ответ бота, обработка голосовых и текстовых сообщений.
3. Вебхуки проверяются через ngrok: он даёт временный адрес, который ведёт на мой компьютер.
4. Ключи API хранятся в файле `.env`, которого нет в репозитории, а в контейнеры передаются как переменные окружения.
5. После проверки деплой выполняется через GitHub.

## Стек

Docker, Docker Compose, n8n, Flowise, ngrok, GitHub, OpenAI API / Anthropic API.

## Что было сложно

Сохранность данных между перезапусками контейнеров и безопасное хранение ключей.

## Что выяснилось на тесте

Звонки не понадобились: люди лучше доводят клиента до продажи.
