# Локальная ИИ-лаборатория: n8n и Flowise в Docker

## Задача

Нужна была площадка, где можно быстро пробовать идеи с LLM: собирать цепочки из блоков, подключать модели и проверять, как работают вебхуки. И чтобы всё поднималось одной командой на любом компьютере.

## Как устроено

1. `docker-compose.yml` описывает сервисы: n8n, Flowise [и база данных, если есть].
2. Каждый сервис запускается в своём контейнере, порты проброшены на localhost.
3. Ключи API хранятся в файле `.env`, которого нет в репозитории, а в контейнеры передаются как переменные окружения.
4. Для проверки вебхуков извне использую ngrok: он даёт временный адрес, который ведёт на мой компьютер.
