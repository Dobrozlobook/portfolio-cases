# Парсер организаций и ИИ-оценка мест размещения

## Задача

Заказчику нужно было быстро понимать, где можно разместить объекты, например автоматы. Для этого требовалось собирать данные об организациях города и оценивать, подходят ли они под заданные критерии.

## Как устроено

1. Всё работает по запросу: задаются город, район и профиль организаций.
2. Парсер собирает организации из Яндекс Карт. Пока Google Карты работали в России, использовались и они.
3. Собранные данные передаются на скоринг: ИИ оценивает, есть ли возможность разместить объекты по критериям.

## Стек

Python, парсинг карт, JSON, LLM.

## Что было сложно

Лимиты источника, «мусор» в данных и большой объём. Решали простыми средствами:

- писали скрипты, которые учитывают лимиты запросов;
- таблица определяла повторы и убирала дубли;
- нужный объём набирали разными запросами.

## Результат

Получилась рабочая цепочка «запрос → сбор организаций → ИИ-оценка»: по городу и району заказчик получает список организаций с оценкой пригодности для размещения.
