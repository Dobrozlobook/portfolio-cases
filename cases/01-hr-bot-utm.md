# Кадровый бот: учёт трафика и подбор вакансий

## Задача

Партнёры приводят кандидатов в кадрового бота в мессенджере МАКС. Нужно было видеть, какой партнёр сколько привёл людей, и подбирать каждому кандидату подходящие вакансии.

## Как устроено

1. Партнёр получает ссылку на бота с UTM-меткой (пометка в ссылке, откуда пришёл человек).
2. Когда кандидат запускает бота, сервис получает эту метку и сохраняет её.
3. Список вакансий поступает по API и из таблицы. Каждая вакансия размещается на определённый срок и снимается по приказу.
4. Главный критерий подбора: готовность кандидата выйти на работу. Учитываются город и другие условия.
5. Лиды передаются дальше тремя способами: в таблицу, по API и сообщением в МАКС. Мы попробовали все три ветки.

## Стек

Python, API мессенджера МАКС, REST API, таблицы, вебхуки.

## Что было сложно

Самым трудоёмким был первоначальный этап: закупка размещений. Многие агрегаторы не дают API для автоматической закупки объявлений, поэтому часть площадок приходилось закупать вручную, а с крупными агрегаторами отдельно договариваться об условиях.

## Результат

Тестовый запуск прошёл успешно: 10 обращений в неделю. Затем систему передали в эксплуатацию. Моя роль — разработка, сопровождением я не занимаюсь.

Решение оказалось универсальным: его применяют и для других заказчиков, с новыми данными и потоками.
